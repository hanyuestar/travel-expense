# 功能能力

旅行路线 · 经费台是一个轻量、零外部依赖的个人旅行管理工具，包含三大模块：

## 1. 路线管理
- 录入 / 查看所有历史 & 新路线。
- 每条路线字段：年份、出行日期、类型（自由行 / 跟团 / 半自由行）、天数、同行人数、主要目的地、景点路线（按天）、住宿位置、备注。
- 列表按年份筛选、关键字搜索（目的地 / 路线名）。
- 顶部「即将出行」区自动把未来日期的行程置顶提醒。

## 2. 旅游花费明细
- 每条路线按 **9 类**拆分花费：
  `交通` · `机票` · `高铁` · `住宿` · `餐饮` · `门票` · `团费` · `购物` · `其他`
- 自动计算**总额**与**人均**（按同行人数）。
- 未填金额计 0，可随时补填，统计实时更新。

## 3. 年度统计复盘
- 按年份汇总：总花费、出行次数、次均花费、总天数。
- 花费分类**占比环形图**（手写 SVG，零外链）。
- 逐年花费**趋势柱状图**。
- 各年明细表。

## 4. 数据与同步
- 所有数据存于你自己的服务器（Docker 挂载卷 `routes.json`）。
- 每次增删改**自动落盘**，换设备登录同一地址即可看到全部数据，无需导入导出。
- 支持「导出 JSON」离线备份与「导入数据」批量合并。

## 5. 自适应
- 手机单列、PC 多列；浏览器「添加到主屏幕」即伪原生 App 体验。

## 技术特性
- 后端：纯 Node 内置 `http`，**零 npm 依赖**，镜像约 50MB。
- 前端：单文件 HTML，全内联 CSS/JS/SVG，无任何第三方请求。
- 存储：单个 `routes.json`，标准 JSON，可直接编辑。
