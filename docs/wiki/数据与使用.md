# 数据与使用

## 数据存储位置（隐私核心）

- **真实数据在你自己的设备上**，不在任何第三方云。
- 后端把全部路线写入挂载卷里的 `routes.json`：
  - Docker 场景：宿主机 `travel-expense/data/routes.json`（容器 `/data`）
  - 手动场景：`DATA_DIR` 环境变量指定的目录，默认 `./data/routes.json`
- 容器每次收到保存/删除请求后**同步写盘**，重启、崩溃均不丢数据（卷已挂载）。

## 日常操作

| 操作 | 说明 |
|---|---|
| 新增路线 | 右上角「新增路线」，填名称 / 年份 / 日期 / 类型 / 天数 / 人数 / 目的地 / 景点路线 / 住宿 / 9 类花费 |
| 编辑 / 删除 | 路线卡片「查看 → 编辑」或「删除」，**自动落盘** |
| 换设备查看 | 登录同一地址即可，无需导入导出 |
| 离线备份 | 右上角「备份 → 导出 JSON」下载一份 |
| 批量导入 | 「备份 → 导入数据」选 JSON 文件，自动合并（按 id 去重） |
| 直接改底层数据 | 编辑 `data/routes.json`（标准 JSON），改完刷新页面 |

## 9 类花费

`交通` · `机票` · `高铁` · `住宿` · `餐饮` · `门票` · `团费` · `购物` · `其他`
只填知道的，留空计 0；自动算总额与人均。

## 备份与迁移

- **备份**：复制 `data/routes.json` 即可，或用工作台「导出 JSON」。
- **迁移到新机器**：把整个 `travel-expense/`（含 `data/`）拷过去，`docker compose up -d`，数据全在。
- **恢复**：把备份的 `routes.json` 覆盖到新机器的 `data/routes.json`，刷新页面。

## 关于 IMA 归档

IMA 知识库是文档型产品，无结构化读写 API，**不适合做实时数据后端**。可把仓库里的 `旅行手账_归档.md` 放进 IMA 作为「只读旅行年鉴」；实时数据仍以本工作台为准。

## 常见问题

- 页面打不开：先 `curl http://localhost:3006/api/routes` 看后端是否起；查 `docker logs travel-expense`。
- 数据没更新：确认 `./data:/data` 挂载正确；直接看 `data/routes.json` 是否变化。
- 换端口：改 `docker-compose.yml` 的 `3006:3000` 左侧。
